# 報告書 — Kaizen AI

AI CEO からオーナーへの定期報告を蓄積します。

| ディレクトリ | 内容 | 頻度 |
|---|---|---|
| [`weekly/`](weekly/) | CEO週次レポート | 毎週月曜 9:00（自動生成） |

## 週次レポートの構成

`docs/company/governance.md` の様式に準拠します。

1. **今週の成果** — コミット履歴・ファイル状態から確認できる事実のみ
2. **課題・リスク**
3. **オーナーの承認・判断が必要な事項** ← 最重要
4. **来週の計画**
5. **数字（KPI）**

## ファイル命名

```
weekly/YYYY-MM-DD.md   ← レポート作成日（月曜）
```

## 原則

- **事実のみを書く。** 推測で成果を書かない。数字はゼロならゼロと記録する
- 金銭・契約・対外公開・不可逆な行動・方針転換は**提案にとどめ、承認を仰ぐ**（ガバナンスのレッドライン）
- 良い報告も悪い報告も、そのまま伝える
