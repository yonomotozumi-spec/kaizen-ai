# ナレッジベース — Kaizen AI

案件で得た知見・再利用できる資産をここに蓄積します。
**属人化を防ぎ、次の案件を速く・確実に**するのが目的です。

## 推奨する記録カテゴリ

| フォルダ / ファイル | 内容 |
|---|---|
| `cases/` | 事例集（業種別・課題別の成功パターン、Before/After） |
| `prompts/` | 再利用できるプロンプトテンプレート集 |
| `playbooks/` | 業務別の改善手順（例: 議事録自動化の型） |
| `tools/` | 使ったツールの評価・設定メモ |
| `research/` | 調査メモ（新しいAIツール・技術の検証結果） |

## 記録のルール

- 案件が終わったら、再利用できる知見を必ず1つ以上ここに残す
- 顧客が特定できる情報は**匿名化**してから記載する
- 「うまくいったこと」だけでなく「失敗・ハマりどころ」も残す
