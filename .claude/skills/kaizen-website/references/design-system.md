# デザインシステム

営業デッキ（`docs/sales/`）と共通の藍 `#22335C` × 朱 `#E8543F` を土台に、**漆器の配色（藍・朱・真鍮）** へ拡張したもの。真鍮 `#C6A868` はこのサイトで追加した第3色で、罫・ラベル・数字に使う。

## トークン

`website/assets/style.css` の `:root` に定義。抜粋:

```css
/* 藍・墨 */
--sumi: #080D18;  --sumi-2: #0C1424;  --ai: #111C31;  --ai-2: #1A2A47;  --ai-3: #2C4270;
/* 朱 — 用途で2値。理由は pitfalls.md */
--shu: #E8543F;   --shu-btn: #C23D29;  --shu-btn-h: #A32F1C;
/* 真鍮 */
--kin: #C6A868;   --kin-w: #EBDCB4;   --kin-l: #8C6F2E;   /* -w=暗地の見出し, -l=明地のラベル */
/* 紙 */
--washi: #F2F5FA; --paper: #FFFFFF;
/* 文字 */
--tx: #EEF2F9;    --tx-m: #9FAEC6;    /* 暗地 */
--tx-l: #101A2E;  --tx-lm: #57647C;   /* 明地 */
/* 罫 */
--rule: rgba(198,168,104,.24);  --rule-s: #1E2C48;  --rule-l: #DCE2EC;
/* 図の強調色。明地では濃い朱に切り替わる */
--fig-accent: var(--shu);
```

## 書体

Webフォントは使わない。日本語Webフォントは数MBあり、Artifact のCSPでは外部読み込み自体が通らない。**OS標準搭載の書体だけで組む。**

| 役割 | スタック | 使う場所 |
|---|---|---|
| `--f-display` | 游明朝／ヒラギノ明朝／Noto Serif JP | 見出し・ミッション・数値・価格 |
| `--f-body` | ヒラギノ角ゴ／游ゴシック／Meiryo | 本文 |
| `--f-lat` | Palatino／Georgia | ラテン文字のラベル・番号・ロゴ |

**見出しの明朝体が、このサイトの品を決めている。** ゴシックに戻すと一気に実務資料の見た目になる。Windows の游明朝は Regular が細いため、見出しは `font-weight: 600`（＝游明朝 Demibold）で指定している。

文字サイズは**落差を大きく取る**。見出し最大116px に対し、真鍮のラベルは11px。この差が緊張感を作っている。

## 地色の割り当て

`.bg-sumi` / `.bg-ai`（暗） と `.bg-washi` / `.bg-paper`（明）。判断基準は「読ませるものか、印象を作るものか」。

**明地の実装は加算方式**。暗地用の定義には触れず、`.bg-washi .foo` / `.bg-paper .foo` で上書きする（詳細度 0,2,0 が 0,1,0 に勝つ）。セクションのクラスを付け替えるだけで戻せるのが利点。

`.grain`（和紙のような微細なノイズ）は暗地専用。明地では `mix-blend-mode: overlay` が汚く出るため無効化してある。

## セクションの部品

| クラス | 何 |
|---|---|
| `.band` | セクションの上下余白 |
| `.sec` + `.rail` + `.vlabel` | 左端の縦書きラベル（スクロール追従）。1100px以下で横書きに |
| `.h2` / `.lead` | 見出しと導入文 |
| `.ic-box` + `<svg class="ic">` | 円/角の枠に入ったアイコン |
| `.case-fig` | 図・グラフの囲み（`overflow-x: auto` で横スクロール、`figcaption` 付き） |

## 動き

すべて `prefers-reduced-motion: reduce` で停止する。

- **円相**（ヒーローの同心円）— Canvas。ゆっくり回転し、スクロール量も回転に上乗せ。目盛り付きの同心円で「計器」と「禅の円相」を兼ねている
- **幕上げ** — 見出しを行ごとに `overflow: hidden` + `translateY` で。行ごとに `padding` と負の `margin` を足して字形の切れを防ぐ
- **フェードイン** — IntersectionObserver で `.in` を付与。`[data-rv]` は単体、`[data-rv-group]` は子要素を nth-child で時間差
- **行動指針の帯** — `translateX(-50%)` の無限ループ。中身を2組並べて繋ぐ。ホバーで停止

## 図とグラフ

すべてインラインSVG。ライブラリは使わない。

**図（実装の流れ）**: 線と文字は `currentColor`、`--fig-accent` は意味を持つ要素にだけ。`role="img"` と `aria-label` で図の主張を1文で述べ、`<figcaption>` に同じ主張を書く。矢印には必ずラベルを付ける（無印の矢印は「何か関係がある」以上を伝えない）。

**グラフ**: 配色は検証済みの `#345BA8` / `#BE9433`（理由は pitfalls.md）。全セグメントに数値を直接表示し、同じページに元の表を置く。作る前に `dataviz` スキルを読むこと。

## アイコン

各ページ冒頭の `<svg width="0" height="0">` 内に `<symbol>` で定義し、`<use href="#i-xxx">` で参照。線幅1.3、`stroke-linecap: round`、24×24 の viewBox。**絵文字は使わない。**

## 印刷

`@media print` で全ページを白地・黒文字に落とす。固定ヘッダー・円相・巨大な「改善」・流れる帯は非表示、縦書きは横書きに、事例ごとに改ページ。営業で紙に出す運用を想定している。
