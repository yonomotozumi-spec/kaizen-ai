# 業務フロー・使用ツール — Kaizen AI

## 案件の標準フロー

```
① 問い合わせ・初回相談
      ↓
② 業務診断（アセスメント）      ← 現状ヒアリング・業務可視化
      ↓
③ 提案・見積り                 ← templates/proposal-template.md
      ↓
④ 契約                         ← templates/engagement-checklist.md
      ↓
⑤ 実行（設計 → 導入）          ← clients/<案件>/ で管理
      ↓
⑥ 効果測定・報告               ← templates/report-template.md
      ↓
⑦ 定着支援・継続提案（顧問へ）
```

### 各ステップの成果物

| ステップ | 主な成果物 | 保存先 |
|---|---|---|
| ② 診断 | 業務診断レポート、改善マップ | `clients/<案件>/01_診断/` |
| ③ 提案 | 提案書、見積書 | `clients/<案件>/02_提案/` |
| ④ 契約 | 契約書、NDA、チェックリスト | `clients/<案件>/03_契約/` |
| ⑤ 実行 | 設計書、実装物、手順書 | `clients/<案件>/04_実行/` |
| ⑥ 報告 | 効果測定レポート | `clients/<案件>/05_報告/` |

## 効果測定の考え方

改善は必ず **Before / After** を数字で残す。

| 指標カテゴリ | 例 |
|---|---|
| 時間 | 作業時間（分/件）、月間削減時間 |
| コスト | 人件費換算、外注費削減 |
| 品質 | エラー率、手戻り件数 |
| 量 | 処理件数、対応可能キャパ |

## 情報セキュリティの原則

- 顧客データは最小限の取得にとどめ、目的外利用しない
- APIキー・認証情報は環境変数で管理し、**コミットしない**
- 顧客の機密文書はこのリポジトリに置かず、必要な場合は `.gitignore` で除外
- 生成AIに顧客機密を入力する際は、顧客の許諾と利用規約（学習利用オフ等）を確認
