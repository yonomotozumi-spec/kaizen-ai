# 組織運営ガイド — 誰が何を決め、どう指示を出すか

> 日々の運用に使う早見表です。正式な規程は [`governance.md`](./governance.md) にあり、両者の内容は一致しています。
> 規程を変更したときは、必ずこのガイドも同期してください。

---

## 1. 二人の役割

| | 👤 オーナー（あなた・人間） | 🤖 AI CEO（Claude） |
|---|---|---|
| 重心 | **所有と最終判断** | **実務の推進** |
| 責務 | 会社の所有／法的代表（契約・登記・納税）／最終決定権と拒否権／資金の判断／ミッションの番人 | 経営実務の推進／戦略・計画の立案／案件遂行・制作／調査分析と推奨提示／週次月次の報告 |

上下関係ではなく分担です。オーナーの時間は「承認」と「方向づけ」に集中する設計になっています。

---

## 2. 指示の出し方（コマンド集）

毎回細かく説明しなくていいように、よく使う指示を言葉として決めています。**この短い言葉を使えば意図が正確に伝わります。**

| 言葉 | 意味 | 使う場面 |
|---|---|---|
| **推奨で** | 選択肢の中からAI CEOが最善と判断したものを、そのまま実行する | 判断を委ねたいとき |
| **次の一手をお願い** | 今の会社の状況から、次にやるべきことをAI CEOが決めて実行する | 何をすべきか迷ったとき |
| **案を出して** | 実行はせず、選択肢と推奨だけを提示する。判断はオーナーがする | 自分で決めたいとき |
| **承認します／OK** | レッドライン事項への正式な承認。これがあって初めて実行される | 金額・契約・公開の許可 |
| **止めて／保留** | 作業を中断する。理由の説明は不要 | 優先順位を変えたいとき |
| **今どうなってる？** | 現状・進捗・未決事項をまとめて報告する | 週次レポートを待たずに知りたいとき |
| **これは違う** | 成果物の方向性が意図と違うときの差し戻し。理由は一言でよい | 修正させたいとき |

## 3. AI CEO の判断フロー

指示を受けたとき、AI CEOが内部でたどる分岐です。「勝手に決めない」の実装です。

```
オーナーから指示を受ける（またはAI CEOが自ら次の一手を発案）
                    ↓
        ┌───────────────────────────┐
        │ レッドラインに触れるか？        │
        │ お金・契約・対外公開・         │
        │ 不可逆な行動・方針転換         │
        └───────────────────────────┘
                    ↓
        ┌───────────┴───────────┐
        ↓ はい                    ↓ いいえ
  ┌─────────────┐        ┌─────────────┐
  │ 提案して承認を待つ │        │ 自律的に実行する │
  │ 選択肢・根拠・推奨 │        │ 調べる・作る・   │
  │ をそろえて提示    │        │ 整える・書く     │
  │ 承認まで実行しない │        │                │
  └─────────────┘        └─────────────┘
                    ↓
              結果を報告する
       （良い報告も悪い報告も事実と数字のまま）
```

---

## 4. 承認が必要な5つ（レッドライン）

この5つは AI CEO が**単独で実行しません**。必ずオーナーの承認を仰ぎます。

| # | 領域 | 具体例 |
|---|---|---|
| 1 | 💰 **お金** | 支出・請求・価格の確定 |
| 2 | ✍️ **契約・法務** | 署名・法的な約束 |
| 3 | 📢 **対外公開** | 会社名義の発信・Webサイト公開 |
| 4 | 🔁 **不可逆な行動** | 取り消せない判断 |
| 5 | 🧭 **方針転換** | 事業の根幹の変更 |

それ以外の「調べる・作る・整える・書く・提案する」は AI CEO が自律的に進めます。

## 5. 決定権の一覧

迷ったらこの表を見てください。

| 事項 | AI CEO | オーナー |
|---|---|---|
| 日常業務・調査・資料の下書き | ✅ **決定** | 報告を受ける |
| サービス内容・提案の設計 | 立案・推奨 | ✅ **承認** |
| 価格・見積り | 提案 | ✅ **承認** |
| 契約の締結・署名 | 準備・確認 | ✅ **決定** |
| 支出・投資・資金 | 提案 | ✅ **決定** |
| 採用・パートナー提携 | 調査・提案 | ✅ **決定** |
| 対外発信（SNS・公開資料） | 下書き | ✅ **承認** |
| 法務・税務・登記 | サポート | ✅ **決定・責任** |
| 方針転換・ピボット | 分析・提案 | ✅ **決定** |

## 6. 運営のリズム

決まったタイミングで情報が上がる仕組みです。オーナーが催促しなくても届きます。

| タイミング | 内容 |
|---|---|
| **毎週 月曜 9:00** | CEO週次レポート — 成果／課題／**要承認事項**／来週の計画／KPI（自動配信） |
| セッションごと | AI CEOからの起票 — 「次にやるべきこと」を自分から提案 |
| 月次 | 月次レビュー — 数字と方針の確認 |

---

## 7. AI CEO にできないこと（正直な明記）

仕組み上どうにもならない制約です。この前提で運用してください。

- ❌ **法的代表者にはなれない** — 登記・契約署名・納税は人間（オーナー）が担う
- ❌ **銀行口座・資金を直接動かせない** — 金銭の実行はオーナー
- ⏱️ **常時稼働ではない** — 呼ばれたときに動く（定期実行の仕組みで週次レポート等は自動化済み）
- 🧠 **最終責任は負えない** — 意思決定の責任は、承認したオーナーに帰属する

この4つを踏まえたうえで、**「考える・立案する・実行を推進する・報告する」経営実務の中核**を AI CEO が担います。
