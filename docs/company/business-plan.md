# 事業計画 — Kaizen AI

> ドラフト。数字・前提は事業の進捗にあわせて更新する。

## 1. 事業の背景・課題

- 生成AIの登場で業務効率化のポテンシャルが急拡大したが、**現場では「何にどう使えばいいか分からない」** 状態が大半。
- 特に中小企業・非IT部門はノウハウ・人材が不足し、AI活用が進まない。
- ツール導入だけでは定着せず、**伴走型の支援** に需要がある。

## 2. 提供価値（バリュープロポジション）

| 顧客の悩み | Kaizen AI の提供価値 |
|---|---|
| 何から手をつければいいか分からない | 業務診断でAI適用領域を特定し、優先順位をつける |
| ツールを入れたが使われない | 現場に合わせた設計・教育・運用ルールで定着させる |
| 社内にAI人材がいない | 内製化支援・研修で自走できる状態をつくる |
| 効果があるか不安 | 削減時間・コストを定量で示し、小さく検証してから拡大 |

## 3. 収益モデル

| モデル | 概要 | 想定単価 |
|---|---|---|
| **顧問契約（リテイナー）** | 月額固定で継続的に改善を支援 | 月 15〜50万円 |
| **プロジェクト型** | 特定業務の自動化・AI導入をスポットで | 30〜300万円/件 |
| **ワークショップ・研修** | 生成AI活用研修、プロンプト研修 | 10〜50万円/回 |
| **診断（アセスメント）** | 業務診断＋改善提案レポート | 20〜80万円 |

> まずは **診断 → プロジェクト → 顧問** と関係を深めていく流れを基本とする。

## 4. ロードマップ

### フェーズ1（0〜6ヶ月）: 立ち上げ・実績づくり
- [ ] 法人設立・銀行口座・会計freee等の整備
- [ ] サービスメニュー・料金の確定（[サービスカタログ](../services/service-catalog.md)）
- [ ] Webサイト・会社紹介資料の作成
- [ ] 初回顧客 1〜3社の獲得（知人紹介・小規模から）
- [ ] 提供事例・ノウハウの蓄積（`knowledge/` に記録）

### フェーズ2（6〜18ヶ月）: 型化・横展開
- [ ] 成功事例をパッケージ化（業種別テンプレート）
- [ ] 顧問契約の比率を高め、収益を安定化
- [ ] 協業パートナー（開発会社・士業）との連携
- [ ] 自社の効率化ツール・ノウハウの資産化

### フェーズ3（18ヶ月〜）: スケール
- [ ] 人材採用・チーム化
- [ ] 特定業種特化のプロダクト化検討
- [ ] 継続的な改善サイクルの仕組み化

## 5. KPI（例）

| 指標 | 目安 |
|---|---|
| 月次経常収益（MRR） | 顧問契約の積み上げで管理 |
| 稼働顧客数 | フェーズ1で 3社、フェーズ2で 10社 |
| 顧客あたり削減時間 | 案件ごとに Before/After を測定 |
| リピート・継続率 | 顧問契約の継続月数 |

## 付録: 法人設立チェックリスト（日本）

> 実際の手続きは専門家（司法書士・税理士）への相談を推奨。以下は一般的な流れの目安。

- [ ] 法人形態を決める（株式会社 / 合同会社(LLC)）
  - 合同会社: 設立費用が安い（登録免許税6万円〜）、スピード重視向き
  - 株式会社: 信用力が高い、資金調達しやすい（登録免許税15万円〜）
- [ ] 会社名（商号）・事業目的・本店所在地を決める
- [ ] 資本金の額を決める
- [ ] 定款を作成（株式会社は公証役場での認証が必要）
- [ ] 法務局へ設立登記を申請
- [ ] 税務署・都道府県・市区町村へ開業届等を提出
- [ ] 法人銀行口座の開設
- [ ] 会計ソフト（freee / マネーフォワード等）の導入
- [ ] 社会保険（年金事務所）の手続き
- [ ] 必要に応じて各種契約書雛形・利用規約の整備
