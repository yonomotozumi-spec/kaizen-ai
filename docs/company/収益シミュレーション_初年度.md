# 初年度収益シミュレーション — サマリー

> 詳細モデル: [`収益シミュレーション_初年度.xlsx`](./収益シミュレーション_初年度.xlsx)（前提を変えると全体が再計算されます）
> ⚠️ **全て仮置きの前提に基づく試算**です。市場統計ではなく、営業活動量と転換率から積み上げた社内モデルです。実績が出たら随時更新します。

## ターゲット業種の選定: 不動産業界

初年度のビーチヘッド（最初に攻める市場）として**不動産業界（仲介・管理・売買仲介の中小事業者）**を選定。

| 選定理由 | 内容 |
|---|---|
| **オーナーの強み** | 不動産適正価値診断アプリを自社開発済み。ドメイン知識＋「見せられる実績」が既にある |
| **AI効率化との相性** | 契約書・重要事項説明・物件資料・査定書など定型文書業務が多く、効果を数字で示しやすい |
| **営業との相性** | 紹介文化が強く、知人経由の営業（立ち上げ期の主戦略）と噛み合う |
| **横展開** | 成功事例は建設・士業など隣接業界へ展開しやすい |

※ 不動産に「限定」はしない。他業種の相談も受けるが、営業資源・事例づくりは不動産に集中する。

## モデルの構造

```
無料相談 → 業務診断（転換率r1） → プロジェクト（r2・翌月受注） → 顧問契約（r3・翌月開始、月次解約率あり）
                                                                ＋ 研修（四半期ごと）
```

- 立ち上がり係数: 1〜3ヶ月目 50% → 4〜6ヶ月目 75% → 7〜12ヶ月目 100%
- 単価（仮置き・サービスカタログのレンジ内）: 診断40万 / プロジェクト80万 / 顧問月20万 / 研修25万
- コスト: 固定費 月10万（ツール3＋経費7）＋変動費 売上の5% ※役員報酬・税金・設立費用は含まない

## CEOの読み（示唆）

1. **最重要レバーは「月間相談件数」** — 単価や転換率より、相談の入口を作れるかが初年度を決める。だから営業開始キット（紹介依頼＋相談台本）が最優先施策。
2. **保守シナリオ（月2件相談）でも黒字** — 固定費が軽いため、月1〜2件の相談を続けられれば事業として成立する。心理的にも「まず月2件」から始めればよい。
3. **顧問の積み上がりは2年目の武器** — 初年度の顧問売上は小さいが、年末稼働2件（標準）は2年目の安定収益基盤になる。初年度は「診断→プロジェクトで実績と信頼を作る年」。
4. **標準シナリオの含意** — 月4件の相談＝週1件。知人紹介＋LP＋事例発信で現実的に狙えるライン。

## 使い方

1. Excelの**「前提条件」シートの青字セル**だけを編集する（黄色塗りが最重要レバー）
2. 月次シート・シナリオ比較は自動再計算される
3. 実績が月次で出たら、前提を実績値に置き換えて精度を上げる
