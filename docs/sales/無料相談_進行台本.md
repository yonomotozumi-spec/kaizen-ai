# 無料相談（60分）進行台本 — 営業開始キット②

初回無料相談のアジェンダ・質問リスト・切り返し集。
ゴールは**「売る」ことではなく、①相手の課題を正確に掴む ②その場で価値を1つ渡す ③次のステップ（業務診断）に合意する**の3つ。

---

## 進行アジェンダ（60分）

| 時間 | パート | やること |
|---|---|---|
| 0–5分 | オープニング | 自己紹介（1分）・本日の流れ説明・「売り込みはしない」宣言 |
| 5–25分 | ヒアリング | 下の質問リストで現状の業務と困りごとを掘る。**話す割合は相手8:自分2** |
| 25–40分 | その場提案 | 聞いた内容から「AIで楽になりそうな業務トップ3」をその場で挙げ、それぞれ何がどう変わるかを具体的に説明 |
| 40–50分 | 進め方の説明 | 診断→設計→導入→定着の流れ、業務診断の内容と目安金額を提示 |
| 50–58分 | 質疑・クロージング | 疑問に答え、次のステップを合意（診断の提案 or 資料送付 or 再面談） |
| 58–60分 | 締め | お礼・今後の連絡方法・（好感触なら）紹介のお願い |

## オープニングの台詞（例）

> 本日はありがとうございます。最初にお約束ですが、今日は売り込みの場ではありません。
> 御社の業務の困りごとを伺って、「AIでどこがどれくらい楽になりそうか」を私なりにその場でお伝えします。それが役に立ちそうなら次の話をしますし、合わなければそれで終わりで大丈夫です。
> 60分、遠慮なく現場の実情を聞かせてください。

## ヒアリング質問リスト

### 基本（全業種共通）
1. 事業内容と体制（人数・役割分担）を教えてください
2. 1週間の中で「一番時間を取られている業務」は何ですか？
3. その業務、月に何時間くらいかかっていますか？（→効果測定のBefore値になる）
4. 「これは人がやらなくてもいいのでは」と感じる作業はありますか？
5. 今、AIやITツールはどんなものを使っていますか？うまくいっていますか？
6. 過去に効率化を試みて、うまくいかなかったことはありますか？その原因は？
7. もし1日2時間浮いたら、その時間で何をしたいですか？（→価値の言語化）

### 不動産業界向けの深掘り
- 物件資料・マイソク・契約書・重説の作成にどれくらい時間がかかっていますか？
- 問い合わせ対応（ポータル反響・電話）は誰が、どう捌いていますか？夜間・休日は？
- 物件情報の入力・転記作業（レインズ・ポータル・自社サイト）は重複していませんか？
- 査定書や提案資料は1件あたりどれくらいで作っていますか？

### 数字を掴む質問（必ず聞く）
- その作業は「月何件 × 1件何分」ですか？
- 担当者の時給換算（ざっくり）でいくらくらいですか？

## その場提案の型

> 伺った中では、①〔業務A〕、②〔業務B〕、③〔業務C〕がAIで効果が出やすいと思います。
> 例えば①は、いま月〔X時間〕かかっているものが、〔具体的なやり方〕で〔目安Y割〕くらい減らせる可能性があります。
> ただ、正確なところは業務の中身を拝見しないと言えないので、もし進めるなら最初に「業務診断」で現状を可視化して、効果の見込みと優先順位をレポートにしてお渡しします。

**注意: その場で断定的な数字を約束しない。**「可能性」「目安」で語り、確定は診断後。

## よくある質問・懸念への切り返し

| 相手の言葉 | 返し方 |
|---|---|
| 「うちはITに弱くて…」 | 「むしろそういう会社のための仕事です。ツールを渡して終わりではなく、現場が使えるようになるまで伴走します。」 |
| 「AIって間違えるんでしょ？」 | 「間違えます。だから全部任せず、AIが下書き・人が確認、という設計にします。できること・できないことは正直にお伝えします。」 |
| 「高いんでしょ？」 | 「最初は業務診断だけ、〔20〜80万円の中でこの規模なら◯万円程度〕で始められます。効果が見えなければそこで止めて構いません。」 |
| 「社内の若手にやらせようかと」 | 「素晴らしいと思います。その方が推進役になれるよう、社内で回る仕組みと教育まで含めて支援する形も可能です。内製化はむしろ歓迎です。」 |
| 「機密情報が心配」 | 「重要な論点です。何をAIに入れてよいか事前に御社と取り決め、学習利用オフの設定など安全なルールを整備するところからやります。」 |
| 「考えます」 | 「ありがとうございます。本日の内容を1枚にまとめてお送りするので、それを見てご判断ください。◯日頃に一度ご連絡してもよいですか？」 |

## クロージング（3段構え）

1. **本命**: 「まず業務診断から始めませんか。〔2〜4週間・◯万円目安〕で、改善マップをお渡しします」
2. **保険1**: 「即決しづらければ、本日の内容をまとめた資料をお送りします。◯日にお電話でご判断を伺います」
3. **保険2**: 「時期尚早であれば、AI活用の情報を時々お送りします。状況が変わったらいつでもどうぞ」

→ どの着地でも**次のアクションと日付**を必ず決めてから終える。

## 相談後24時間以内のフォローメール（型）

> 件名: 本日のご相談のまとめ（Kaizen AI）
>
> 本日はお時間をいただきありがとうございました。内容を簡単にまとめます。
>
> ■ 伺った課題: 〔箇条書き2〜3点〕
> ■ AIで改善できそうな業務: 〔トップ3と期待効果の目安〕
> ■ ご提案した次のステップ: 〔業務診断の内容・期間・目安金額〕
>
> ご不明点があればいつでもご連絡ください。〔約束した日付〕に改めてご連絡いたします。
