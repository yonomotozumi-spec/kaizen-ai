# 営業資料 — Kaizen AI

初回商談・紹介時に使う会社紹介・営業資料と、営業開始キットを管理します。

| ファイル | 用途 |
|---|---|
| `Kaizen-AI-会社紹介.pptx` | 編集用マスター（PowerPoint） |
| `Kaizen-AI-会社紹介.pdf` | 送付・閲覧用 |
| [`紹介依頼テンプレート.md`](./紹介依頼テンプレート.md) | 知人への紹介依頼・紹介先への初回連絡の文面集 |
| [`無料相談_進行台本.md`](./無料相談_進行台本.md) | 60分無料相談のアジェンダ・質問リスト・切り返し集 |

## 構成（9スライド）

1. 表紙
2. こんなお悩みはありませんか？（課題への共感）
3. Kaizen AI とは（ミッション・特徴）
4. 私たちのアプローチ（診断→設計→導入→定着＋効果測定）
5. サービス一覧（7サービス＋自由設計）
6. 料金と始め方（診断からの段階導入を推奨）
7. 選ばれる理由（バリュー＝顧客への約束）
8. ご依頼からの流れ（無料相談→診断→提案→導入）
9. クロージング（無料相談への導線）
