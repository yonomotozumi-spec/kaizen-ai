# 顧客案件の管理

顧客案件はこのディレクトリ配下に**案件ごとのフォルダ**を作って管理します。

## フォルダ命名規則

```
clients/YYYYMMDD_顧客名（またはコードネーム）/
```

例: `clients/20260801_サンプル商事/`

> 機密性が高い顧客はコードネーム（例: `20260801_ClientA`）を使い、
> 実名との対応表は別途安全な場所で管理する。

## 案件フォルダの標準構成

新規案件では以下のサブフォルダを作成します。

```
20260801_サンプル商事/
├── 00_案件メモ.md          ← 概要・連絡先・進捗をここに集約
├── 01_診断/                ← 業務診断レポート・ヒアリングメモ
├── 02_提案/                ← 提案書・見積書
├── 03_契約/                ← 契約書・NDA・チェックリスト
├── 04_実行/                ← 設計書・実装物・手順書
└── 05_報告/                ← 効果測定レポート
```

## 新規案件の始め方

1. このフォルダに `YYYYMMDD_顧客名/` を作成
2. 上記サブフォルダを作成（または過去案件をコピー）
3. `templates/` から必要な雛形を該当サブフォルダにコピー
   - 提案書 → `templates/proposal-template.md`
   - 報告書 → `templates/report-template.md`
   - 契約チェックリスト → `templates/engagement-checklist.md`
4. `00_案件メモ.md` に案件の基本情報を記入して進める

## 案件メモのテンプレート（00_案件メモ.md）

```markdown
# 案件メモ — <顧客名>

- ステータス: 診断 / 提案 / 契約 / 実行 / 報告 / 完了
- 担当: 
- 顧客窓口: 
- 開始日: 
- 契約形態: 診断 / プロジェクト / 顧問

## 課題・ゴール

## 提供サービス

## 進捗ログ
- YYYY-MM-DD  

## 次のアクション
- [ ] 
```

> ⚠️ 顧客の生データ・機密ファイルは `.gitignore` の対象（`raw-data/` 等）に置くか、
> リポジトリ外の安全な場所で管理してください。
