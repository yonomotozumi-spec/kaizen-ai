# 会社Webサイト（LP） — Kaizen AI

会社紹介LP（`index.html`）と改善例ページ（`cases.html`）の2ページ構成です。
外部ライブラリ・外部フォント・外部画像は一切使っておらず、ブラウザで開くだけで表示できます。

## ファイル構成

| ファイル | 内容 |
|---|---|

### グラフ

`cases.html` に2点あります。いずれもインラインSVGで、ライブラリは使っていません。

| グラフ | 内容 |
|---|---|
| `#case-dd` 自動化した範囲 | DD項目18項目・許認可39法令の内訳を積み上げ棒で。**実数** |
| 想定モデルケース群の冒頭 | 4件を「人がやる量の削減率」に揃えた横棒。**試算** |

配色は `#345BA8`（自動）／ `#BE9433`（人が確認）。ブランドの藍・真鍮の色相を保ったまま、
明度と彩度をデータビジュアライゼーションの基準内（OKLCH L 0.43–0.77 / C ≥ 0.10）に上げた値です。
ブランド色そのまま（`#22335C` / `#C6A868`）では明度・彩度が基準を外れ、グラフの塗りとして機能しません。

- 色覚多様性の分離度 ΔE 29.4（基準8以上）・通常視 32.6（基準15以上）で検証済み
- 真鍮は地色とのコントラストが 2.74 で3:1を下回るため、**全セグメントに数値を直接表示**し、
  同じページ上に効果の表を併記することで補っています。この2つは外さないでください

**実例3件は時間削減の実測値が無いため、時間のグラフはありません。**
`#case-dd` のグラフは項目数・法令数という実数のみを扱っています。
数字が取れたら、想定ケースと同じ形式で追加できます。

実装は `powerx-dd-case` スキルにあります。掲載した数値はすべてそこから確認できる事実です。

| 記載 | 根拠 |

#### 未確認・要対応

- **時間削減の実測値は3件とも未掲載。** 数字が取れ次第、追記してください
- **`#case-minutes` は顧客名（kikitori）を実名で掲載しています。** 公開前に**先方の掲載許可**を必ず取得してください。許可が取れない場合は業種のみの匿名表記に変更すること

## デザイン言語

営業デッキ（[`../docs/sales/`](../docs/sales/)）と同じ藍 `#22335C` × 朱 `#E8543F` を土台に、
漆器の配色（藍・朱・**真鍮** `#C6A868`）へ拡張しています。

| 要素 | 方針 |
|---|---|
| **書体** | 見出しは**明朝体**（游明朝／ヒラギノ明朝＝Mac・Windows標準搭載）、本文はゴシック、数字とラテン文字は Palatino 系セリフ |
| **文字サイズ** | 落差を大きく取る。見出し最大116px に対し、真鍮のラベルは11px |
| **アイコン** | 絵文字は使わず、すべてインラインSVG（`<symbol>` 定義を `<use>` で参照）。環境による見た目のブレを排除 |
| **地色** | **暗は印象、明は情報**。ヒーロー・ミッション・行動指針の帯・アプローチ・最終CTAは藍（`#080D18` / `#111C31`）、読ませるセクションは紙白（`#F2F5FA` / `#FFFFFF`）を交互に敷く |
| **ヒーロー** | 巨大な「改善」を縦に組み、画面右端から断ち落とす。真鍮の輪郭線で抜き、円相（同心円）を重ねる |
| **セクションラベル** | 左端に縦書きで置き、スクロールに追従させる（ページの背骨） |
| **サービス一覧** | 障子の格子に見立てた1pxグリッド |
| **アプローチ** | 01–04 を白抜きの巨大数字で |
| **行動指針** | 全幅の帯を横に流す（明朝・大サイズ） |
| **ミッション** | 縦書き（`writing-mode: vertical-rl`） |
| **配色モード** | ブランドの単一トーンに固定。ダークモード切替はせず、背景・文字色をすべて明示指定 |

### 動きについて

- ヒーローの同心円は Canvas 描画（円相＋計器の目盛り）。ゆっくり回転し、スクロール量も回転に上乗せする
- 見出しは行ごとに幕が上がるように出る（`overflow: hidden` ＋ `translateY`）
- スクロールに応じた各セクションのフェードイン（IntersectionObserver）
- 行動指針の帯は横に流れ続ける（ホバーで一時停止）
- いずれも `prefers-reduced-motion: reduce` で停止

### コントラスト

全13組の文字色・地色の組み合わせでWCAG基準を満たしています（本文15.15／補助文7.57など）。

朱は用途で2値に分けています。**面で塗るときは白文字とのコントラストが要る**ためです。

| 変数 | 値 | 用途 | コントラスト |
|---|---|---|---|
| `--shu` | `#E8543F` | 文字・罫・図の強調 | 藍地の上で 4.68（大見出し基準3.0） |
| `--shu-btn` | `#C23D29` | ボタンの塗り | 白文字 5.26（基準4.5） |

`--shu` をボタンに使うと白文字が **3.64** となり基準を割ります。塗りには必ず `--shu-btn` を使ってください。

### 印刷

`@media print` で全ページを白地・黒文字に落とします。固定ヘッダー・円相・巨大な「改善」・
流れる帯など画面用の装飾は非表示、縦書きは横書きに戻し、事例ごとに改ページします。
営業で紙に出す運用を想定しています。

### 1pxグリッドの引き方

サービス一覧・改善例・目次などの格子は、**コンテナ背景ではなくセルの `box-shadow` で引いています**。
コンテナ背景を罫色にする方式だと、要素数が列数の倍数でないときに空セルが色の塊になって出るためです
（目次7件・サービス8件が該当）。

### 環境依存への対応

縦書きは、書体が縦組み用の字送り情報を持たない環境（日本語の明朝体が入っていないLinux等）では
文字が重なって崩れます。読み込み時に字送りを実測し、成立しない場合は自動で横書きに退避します
（`<html>` に `no-vert` クラスを付与）。
