# 会社Webサイト（LP） — Kaizen AI

`index.html` 1ファイルで完結する会社紹介LP（ランディングページ）です。
外部ライブラリ・外部フォント不要で、ブラウザで開くだけで表示できます。

## 構成

ヒーロー → お悩み → 会社紹介（ミッション） → サービス一覧 → アプローチ → 料金 → 選ばれる理由 → ご依頼の流れ → FAQ → 無料相談CTA

営業デッキ（[`../docs/sales/`](../docs/sales/)）と同じデザイン言語（藍 `#22335C` × 朱 `#E8543F`）・同じ内容で統一しています。

## 公開方法（いずれか）

| 方法 | 手順 | 備考 |
|---|---|---|
| **Vercel / Netlify（推奨）** | アカウント作成 → このリポジトリを連携 → Root Directory を `website` に設定 | 無料枠で公開可・独自ドメイン設定可 |
| **GitHub Pages** | リポジトリ Settings → Pages → Branch: main / folder 指定 | **無料プランのPrivateリポジトリでは不可**（Publicにするか有料プラン） |
| **レンタルサーバー** | `index.html` をアップロードするだけ | |

> ⚠️ このリポジトリには顧客情報を置くため、**リポジトリ自体をPublicにするのは非推奨**。
> 公開はVercel/Netlify連携か、`website/` だけを別の公開用リポジトリに切り出すのが安全です。

## Canva版（参考HP・デザイン検討用）

`index.html` と同じ構成・同じ文言で、Canva Doc 版を作成済みです。ノーコードで編集でき、Canvaエディタから**そのままウェブサイトとして公開**できます（`canva.site` サブドメイン無料／独自ドメイン可）。

| 項目 | 値 |
|---|---|
| デザイン名 | AIで、日本の現場に "改善" を。 |
| デザインID | `DAHR2XXGgjg` |
| 形式 | Canva Doc（1ページ・縦スクロール） |

Canvaのホーム画面かデザインIDから開けます。

**Canvaから公開する手順**: デザインを開く → 右上「共有」→「ウェブサイト」→ ページ形式（スクロール推奨）を選択 → 公開。

### どちらを本番にするか

| | `index.html` | Canva Doc版 |
|---|---|---|
| デザイン自由度 | 高い（CSSで完全制御） | 中（Canvaの範囲内） |
| 更新のしやすさ | 要HTML知識 | 誰でも可 |
| 独自ドメイン | 可（Vercel等） | 可（Canva有料プラン） |
| 想定用途 | **本番サイト** | デザイン検討・暫定公開・社内共有 |

> ⚠️ 2つは自動同期しません。料金・サービスを変更したら**両方**を更新してください。
