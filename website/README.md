# 会社Webサイト（LP） — Kaizen AI

`index.html` 1ファイルで完結する会社紹介LP（ランディングページ）です。
外部ライブラリ・外部フォント不要で、ブラウザで開くだけで表示できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（1枚ものLP） |
| `cases.html` | 改善例（モデルケース4件）。`#case-01`〜`#case-04` で個別にリンク可能 |
| `assets/style.css` | 全ページ共通のスタイル |

## 構成（トップページ）

ヒーロー → お悩み → 会社紹介（ミッション） → 行動指針の帯 → サービス一覧 → アプローチ → **改善例** → 料金 → 選ばれる理由 → ご依頼の流れ → FAQ → 無料相談CTA

## ⚠️ 改善例の扱いについて

`cases.html` には **実例1件** と **想定モデルケース4件** を掲載しています。
両者は必ず区別して扱ってください。

不動産開発会社の用地DD判定を、緯度経度と国土交通省「不動産情報ライブラリ」で
自動化した案件。実装は `powerx-dd-case` スキルにあります。

掲載している数値は、すべてスキルの実装から確認できる事実に基づいています。

| 記載 | 根拠 |
|---|---|
| DD項目 9項目が自動 | `references/dd-items.md` の「自動」列 ◎2件＋○7件 |
| 許認可 5法令に自動反映 | 地すべり→No.13／急傾斜→No.14／土砂(特別)警戒→No.15・16／大規模盛土→No.7 |
| 最大716mのズレ | `SKILL.md` に記載の実測値 |

**時間削減の数値は未掲載です。** 実測値が取れ次第、追記してください。

### 想定モデルケース（`#case-01`〜`#case-04`）

**実在の顧客事例ではありません。** サービス内容と一般的な業務量から組み立てた試算です。

- 各ケースに「想定ケース」バッジを付け、**測り方**と**前提**を併記しています
- トップページと改善例ページの両方に注意書きを常時表示しています
- **実績が出たら実例に差し替えてください。** そのとき注意書きも外します
- 注意書きを外したまま数値を残すと**経歴の詐称になります**。必ずセットで扱ってください

## デザイン言語

営業デッキ（[`../docs/sales/`](../docs/sales/)）と同じ藍 `#22335C` × 朱 `#E8543F` を土台に、
漆器の配色（藍・朱・**真鍮** `#C6A868`）へ拡張しています。

| 要素 | 方針 |
|---|---|
| **書体** | 見出しは**明朝体**（游明朝／ヒラギノ明朝＝Mac・Windows標準搭載）、本文はゴシック、数字とラテン文字は Palatino 系セリフ |
| **文字サイズ** | 落差を大きく取る。見出し最大116px に対し、真鍮のラベルは11px |
| **アイコン** | 絵文字は使わず、すべてインラインSVG（`<symbol>` 定義を `<use>` で参照）。環境による見た目のブレを排除 |
| **地色** | **全編を藍の闇（`#080D18` / `#111C31`）に沈め、料金セクションだけを白く抜く**。白は「小さく始められる」ことを伝える場所にだけ使う |
| **ヒーロー** | 巨大な「改善」を縦に組み、画面右端から断ち落とす。真鍮の輪郭線で抜き、円相（同心円）を重ねる |
| **セクションラベル** | 左端に縦書きで置き、スクロールに追従させる（ページの背骨） |
| **サービス一覧** | 障子の格子に見立てた1pxグリッド |
| **アプローチ** | 01–04 を白抜きの巨大数字で |
| **行動指針** | 全幅の帯を横に流す（明朝・大サイズ） |
| **ミッション** | 縦書き（`writing-mode: vertical-rl`） |
| **配色モード** | ブランドの単一トーンに固定。ダークモード切替はせず、背景・文字色をすべて明示指定 |

### 動きについて

- ヒーローの同心円は Canvas 描画（円相＋計器の目盛り）。ゆっくり回転し、スクロール量も回転に上乗せする
- 見出しは行ごとに幕が上がるように出る（`overflow: hidden` ＋ `translateY`）
- スクロールに応じた各セクションのフェードイン（IntersectionObserver）
- 行動指針の帯は横に流れ続ける（ホバーで一時停止）
- いずれも `prefers-reduced-motion: reduce` で停止

### 環境依存への対応

縦書きは、書体が縦組み用の字送り情報を持たない環境（日本語の明朝体が入っていないLinux等）では
文字が重なって崩れます。読み込み時に字送りを実測し、成立しない場合は自動で横書きに退避します
（`<html>` に `no-vert` クラスを付与）。

## 公開方法（いずれか）

| 方法 | 手順 | 備考 |
|---|---|---|
| **Vercel / Netlify（推奨）** | アカウント作成 → このリポジトリを連携 → Root Directory を `website` に設定 | 無料枠で公開可・独自ドメイン設定可 |
| **GitHub Pages** | リポジトリ Settings → Pages → Branch: main / folder 指定 | **無料プランのPrivateリポジトリでは不可**（Publicにするか有料プラン） |
| **レンタルサーバー** | `index.html` をアップロードするだけ | |

> ⚠️ このリポジトリには顧客情報を置くため、**リポジトリ自体をPublicにするのは非推奨**。
> 公開はVercel/Netlify連携か、`website/` だけを別の公開用リポジトリに切り出すのが安全です。
